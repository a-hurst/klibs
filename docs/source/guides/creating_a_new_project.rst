Creating A New Project
======================

Once klibs is installed, creating your first project is easy.

First, open a terminal window and navigate to the folder where you want to put
the project (e.g. ``cd ~/Documents/Experiment Code``). Then, simply run::
    
    klibs create NewTask
    
in the terminal, replacing "NewTask" with whatever you want to name your task.
You will be guided through the creation process with a few prompts and a new
folder will be created containing the template of your new task.
